# Number Guessing Game 🎯

A simple **Number Guessing Game** written in Python.

The computer randomly selects a number between **1 and 100**, and the player keeps guessing until they find the correct number. The program gives hints after every guess.

## 📌 About the Project

This is a beginner-friendly Python project created to practice:

* Python `random` module
* `random.randint()`
* User input
* Variables
* `while` loops
* Conditional statements
* `if` and `else`
* f-strings
* Basic game logic

## 🎮 How the Game Works

1. The computer randomly generates a number between **1 and 100**.
2. The player enters a guess.
3. If the guess is higher than the secret number, the program says:
   **"lower number please"**
4. If the guess is lower than the secret number, the program says:
   **"higher number please"**
5. The game continues until the player guesses the correct number.
6. The total number of attempts is displayed at the end.

## 💻 Example

```text
guesse the number: 50
lower number please
guesse the number: 25
higher number please
guesse the number: 37
higher number please
guesse the number: 43
lower number please
guesse the number: 40
you have guessed the number 40 correctly in 5 attempt
```
